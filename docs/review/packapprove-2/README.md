# PackApprove 2.0 — браузерные снимки

Настоящие PNG из Playwright Chromium, снятые с работающего Next.js и локального PostgreSQL/Supabase стенда. Это самостоятельная визуальная концепция Packaging Operations Studio, а не подтверждённый официальный брендбук QAZALPACK. Скриншоты не генерировались и не ретушировались; PDF-просмотр и миниатюры сняты после завершения реального рендера PDF.js.
