Добавляет шесть оригинальных концепций напитков с PNG/PDF, девять сохранённых версий и явную команду импорта для администратора. Публичная can-lab расширена без доступа к клиентским API; проекты используют существующие приватные файлы, 2D/3D, историю и сравнение.

Импорт требует подтверждения и существующих исполнителей, защищён RLS, глобальной транзакционной блокировкой, ключом идемпотентности и неизменяемым аудитом. Не создаёт пользователей, фиктивных решений и технической готовности. Разные этапы подготовлены отдельным скриптом только для локального стенда. Production не изменялся; миграций нет. Обычные права дизайнера, клиента и производства сохранены.

Инструкция публикации и ограничения: docs/SHOWCASE.md. Не объединять автоматически.

Проверено локально: TypeScript и production build; 101 Vitest; SQL/RLS и scratch-миграции; полный Playwright — 62 passed, 2 прежних skipped, 0 failed (desktop + mobile). В docs/showcase сохранены настоящие браузерные скриншоты.

Общий бюджет CI-job увеличен до 45 минут: workflow выполняет два полных прогона, теперь каждый включает дополнительно шесть WebGL-концепций на двух размерах экрана. Лимиты отдельных тестов и проверки безопасности не ослаблены.
